# Quetzal-1 Telemetry Processing Scripts

Scripts to decode the [raw weekly beacons](../raw/) into CSV files. They were originally written by **Aldo Aguilar Nadalini** for the Quetzal-1 CubeSat Team in 2020 and are kept as close as possible to the original code (including the Spanish comments).

| File | Description |
|------|-------------|
| `Modulo_HEX.py` | Quetzal-1 beacon decoder. Unmodified original. |
| `Telemetry_Filter.py` | Decodes one week (or all weeks) of raw beacons, converts the satellite clock to UTC and writes a CSV file. Optionally applies a deduplication filter. |

## Requirements

Python 3. No third-party packages are needed.

## Usage

Run from any directory:

```
python Telemetry_Filter.py --week 5             # every frame of week 5
python Telemetry_Filter.py --week 5 --filter    # week 5, filtered
python Telemetry_Filter.py --all                # every frame of all 30 weeks
python Telemetry_Filter.py --all --filter       # all 30 weeks, filtered
```

By default the input is `../raw/beacons_week_N.hex` and the output is `./output/beacons_week_N.csv` (`beacons_week_N_filtered.csv` with `--filter`). For a single week, `--input` and `--output` can be used to choose other files.

## Output

One row per frame, with the columns:

- `frame_index`: position of the record in the raw file (record *n* starts at byte *n* × 137).
- `UTC_Timestamp`: UTC time of the beacon, in the format `hh:mm:ss - dd/MM/yyyy`.
- The 83 decoded beacon fields, described in the [variable description](../variable_description.xlsx).

The beacon only carries the satellite's real-time clock, counted from launch. It is converted to UTC by adding it to the launch time (2020-04-28 15:20:18 UTC) and correcting the clock drift of the on-board computer (skew coefficient 0.999939265156109).

## Filtering

Without `--filter`, **every** record of the raw file is written, including duplicates and some non-beacons described in the [raw data README](../raw/README.md). This gives 101,056 rows for the 30 weeks.

With `--filter`, the following filter is applied: a frame is kept only if its UTC timestamp is strictly later than the last kept frame of the same file and before the year 2030. This removes duplicates, frames with corrupted clocks and the non-beacon records. The result for the 30 weeks is 75,994 rows, which is what was made available as the final data in [telemetry.xlsx](../telemetry.xlsx).

## Pending work

The CSV files generated by [Telemetry_Filter.py](./Telemetry_Filter.py) do not contain the position and velocity columns that [telemetry.xlsx](../telemetry.xlsx) contains. These were added by propagating the satellite's orbit based on each week's TLE (Two-Line Element). We may or may not update this repository in the future to include the code that was used for the orbit propagation.
